## SVS344 - Modernizing .NET to Serverless: Native AOT and SnapStart, live
AWS re:Invent 2026

### Session Type
Code Talk

### Abstract
.NET workloads on Lambda have historically meant slower cold starts and JIT warmup time that doesn't match Serverless execution patterns. Native AOT and SnapStart on .NET 10 close that gap, bringing cold starts under 200ms, but modernization isn't flip-a-switch. In this code talk, modernize a .NET function to AOT live, watch it fail, then fix it on stage: serialization with source generators, reflection-based DI replaced, trimming warnings resolved. See real measurements across AOT, SnapStart, and the managed runtime. Walk away with a library compatibility matrix and modernization patterns for your own .NET Serverless journey.
